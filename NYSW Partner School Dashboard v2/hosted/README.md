# NYSW Partner School Dashboard (hosted)

Login, shared notes, editable rubric with version history, action queue and email digests. Zero npm dependencies (Node 20+).

- Run locally: `ADMIN_EMAIL=you@example.org ADMIN_PASSWORD=<temp> node server.js` then open http://localhost:3000
- Deploy: see [DEPLOY.md](DEPLOY.md)
- `seed/data.json` contains school, staff and teacher names from Accelo exports. **Keep this repository private.**
